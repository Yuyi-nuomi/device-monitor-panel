PCT_100 化工控制实训装置 · 说明书 V2.0

1.产品总览

PCT_100 是基于 ESP32 的化工过程控制教学实训装置，采用 FreeRTOS 多线程实时系统，集成温度采集、光照检测、OLED显示、RGB状态指示、继电器输出、WiFi配网、MQTT物联网远程控制，完全模拟工业化工泵阀控制系统，适合教学实训、课程设计、技能竞赛使用。

2.硬件组成明细

IO 外设

  • RGB彩灯：GPIO0
  • 光敏传感器：GPIO1
  • OLED屏幕：GPIO4/SDA，GPIO5/SCL
  • 温度传感器：GPIO10
  • KEY1：GPIO20
  • KEY2：GPIO21
  • 继电器：GPIO7

物联网配置

MQTT服务器：47.98.170.18:8081
设备ID：PCT_100_28
通信协议：WiFi + MQTT 3.1.1

3.整机功能介绍

  • ✅ 温度实时采集（DS18B20）
  • ✅ 光照强度模拟采集（光敏电阻）
  • ✅ OLED屏幕实时显示：温度/光照/WiFi/模式
  • ✅ RGB彩灯10种状态指示：正常/报警/离线/运行
  • ✅ 自动模式：阈值自动控制灯光+风扇
  • ✅ 手动模式：4档手动控制输出
  • ✅ WiFi自动配网 + 掉电记忆
  • ✅ MQTT远程控制与状态上报
  • ✅ 按键多级逻辑：短按/长按/超长按

4.整机技术参数

项目参数
主控芯片ESP32（RISC-V + 双核）
系统架构FreeRTOS 多线程
工作电压DC 5V

输出控制1路继电器 + 1路LED
通信方式WiFi + MQTT

5.源码分层结构

  • led.h / led.cpp —— LED驱动
  • key.h / key.cpp —— 按键消抖
  • relay.h / relay.cpp —— 继电器控制
  • exit.h / exit.cpp —— 系统复位
  • PCT_100.ino —— 主逻辑（多线程+MQTT+传感器）

6.上电使用步骤

  1. 设备上电 → RGB彩灯闪烁启动
  2. 自动扫描WiFi → 串口配网
  3. WiFi连接成功 → OLED显示IP
  4. KEY1 短按 → 启动系统
  5. KEY2 长按 → 切换自动/手动模式
  6. KEY2 短按 → 手动切换输出档位

7.日常保养规范

设备应存放于干燥、无尘、无腐蚀性气体环境；每月检查供电电压与接线端子；禁止带电拔插传感器；长期不使用时断电存放于避光干燥处；继电器与按键为机械损耗件，使用次数≥10万次。

8.故障排查指南

🔹 WiFi无法连接：长按KEY2重置

🔹 温度不显示：检查DS18B20接线

🔹 OLED不亮：检查I2C接线

🔹 MQTT离线：检查网络与服务器

🔹 按键无反应：检查GPIO接线

🔹 继电器不动作：检查供电与负载
